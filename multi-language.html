How it works

Multi-language interface in practice

Per-user language, instantly.

Each staff login chooses its own interface language. The same till serves a morning cashier in one language and an evening cashier in another, with no settings dance.

✓Interface language set per user profile
✓Right-to-left script support
✓Product names maintainable in multiple languages
✓Switch languages without restarting or resyncing

Receipts and kitchen tickets, localised.

Customer receipts print in your market’s language while kitchen tickets print in the kitchen’s. Every audience gets the version it can act on.

✓Receipt language independent of interface language
✓Kitchen tickets in the kitchen’s working language
✓Localised number, currency and date formats
✓Tax terminology matched to local requirements

Questions

Frequently asked

Which languages are available?

Coverage is expanding by market. Contact us with your requirement and we will confirm current availability for your languages.

Can product names differ by language?

Yes, products can carry names per language, used on the matching screens and prints.

Does language affect reporting?

Reports render in the viewer’s chosen language. Numbers, naturally, stay the same.

Is right-to-left fully supported?

Yes, layouts mirror correctly for right-to-left scripts across the interface.
